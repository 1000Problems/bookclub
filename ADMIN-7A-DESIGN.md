# Admin 7a and Members 6a

Source: `Book club admin redesign v2.zip`. `Admin Meetings.dc.html` section 7a, `Members Page.dc.html` section 6a.

## Admin 7a: one page, saves as you go
- One Admin page. Header: "Admin", "N members · next meeting <weekday, month day> · everything saves as you go", links to Members, Meetings, Club. `/admin/club` redirects to `/admin#club`.
- **Members**: a ledger with Member, Sign-in, Role, Actions.
  - Sign-in: signed in since a date, invite out with expiry, or no sign-in yet.
  - Role: Member / Admin switch. Every change asks first in a popup. You: "Admin · can't change". The last admin can't be made a member.
  - Actions: Get invite link; Copy link and Cancel invite; Reset sign-in (stops their sign-in and makes a new link); Retire, with an inline confirm.
  - An open invite shows its link: "Text this to <name>. It works once." Studio's invite list now returns the link of open invites (scribes only).
  - + Add member: name, joining month, Member or Admin, Add and get link.
  - Past members fold away, with Bring back.
- **Meetings**: the 4c list and record. No Save button: a pause in typing, a tick, a choice or leaving a field saves the whole row. One save at a time. The tag says Saving…, All changes saved, or Studio's refusal. "Post the five" stays a button: it opens voting.
- **Club**: settings (who can see the site, score reveal, books on each ballot, three switches, books matched with "Match N more"), the black export card, score corrections. All save as you change them.

Kept, not in 7a: books with no edition match (Find this book), sheet labels and birthdays for the export, original sheet cells (now inside the record, saved as you go). The list's filters and search stay out (removed on Angel's request).
